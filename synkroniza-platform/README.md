# منصة Synkroniza لتطوير الأعمال — النسخة المستقلة

نفس السيستم اللي شغّال جوه Claude، بس على منصة **ملك الشركة**:
- دومين خاص بيها.
- تسجيل دخول بصلاحيات.
- قاعدة بيانات بنسخ احتياطية.
- مهام يومية أوتوماتيك.

لو الذكاء الاصطناعي وقف، كل حاجة تانية بتفضل شغّالة.

> **التكلفة الحالية: صفر.** كل المكونات على الخطط المجانية. وقت ما يبقى فيه ميزانية، تحط المفتاح المدفوع في مكانه والمنصة تستخدمه على طول من غير أي تعديل في الكود.

| الجزء | بيعمل إيه | الخدمة | التكلفة |
|---|---|---|---|

## الإعداد خطوة بخطوة (حوالي 45 دقيقة، مرة واحدة)

### 1) حط الكود في Repository خاص
1. على GitHub اعمل Repository جديد **Private** باسم `synkroniza-bd`.
2. ارفع **محتوى** الفولدر ده (`synkroniza-platform`) على المستوى الرئيسي للـ Repository. يعني `README.md` و`web/` و`.github/` يبقوا في الجذر، مش جوه فولدر.

### 2) Supabase (قاعدة البيانات)
1. ادخل [supabase.com](https://supabase.com) واعمل حساب، وبعدين **New project**:
   - المنطقة: أقرب منطقة (مثلاً Frankfurt).
   - كلمة سر قاعدة البيانات: احفظها.
2. من **Project Settings → API** خد:
   - `Project URL` ← ده `SUPABASE_URL`
   - `anon public` ← ده `SUPABASE_ANON_KEY`
   - `service_role` ← ده `SUPABASE_SERVICE_ROLE_KEY` (**سري جداً**، مايتحطش غير في GitHub Secrets)
3. `Reference ID` من **Project Settings → General** ← ده `SUPABASE_PROJECT_REF`.
4. من **Connect → Session pooler** خد رابط الاتصال (URI)، وحط فيه كلمة السر ← ده `SUPABASE_DB_URL`.
   - استخدم الـ pooler تحديداً، لأن GitHub مابيعرفش يوصل للاتصال المباشر.
5. من [supabase.com/dashboard/account/tokens](https://supabase.com/dashboard/account/tokens) اعمل Access Token ← ده `SUPABASE_ACCESS_TOKEN`.

### 3) أسرار GitHub
في الـ Repository: **Settings → Secrets and variables → Actions → New repository secret**، وأضف:

| الاسم | إجباري؟ | منين |
|---|---|---|
| `SUPABASE_URL` | ✅ | خطوة 2 |
| `SUPABASE_SERVICE_ROLE_KEY` | ✅ | خطوة 2 |
| `SUPABASE_PROJECT_REF` | ✅ | خطوة 2 |
| `SUPABASE_DB_URL` | ✅ | خطوة 2 |
| `SUPABASE_ACCESS_TOKEN` | ✅ | خطوة 2 |
| `GEMINI_API_KEY` | للذكاء المجاني | خطوة 6 |
| `ANTHROPIC_API_KEY` | لما يبقى فيه ميزانية | [console.anthropic.com](https://console.anthropic.com) |
| `APOLLO_API_KEY` | لـ Apollo | خطوة 7 |
| `MS_TENANT_ID`, `MS_CLIENT_ID`, `MS_CLIENT_SECRET`, `MS_SENDER`, `MS_DOMAIN` | لإيميل الشركة | خطوة 8 |
| `MS_INBOX`, `MS_INBOX_FOLDER` | اختياري | الصندوق والفولدر اللي بنقرا منه التنبيهات. الافتراضي: `MS_SENDER` و`Leads` |
| `INGEST_KEY` | لـ Manus | أي كلمة سر طويلة تختارها (30 حرف مثلاً) |
| `APP_URL` | اختياري | رابط المنصة بعد خطوة 4، عشان يظهر في الإيميلات |

### 4) شغّل الإعداد
من **Actions → Setup Supabase → Run workflow**. الخطوة دي:
- بتبني قاعدة البيانات.
- بتنقل المفاتيح للسيرفر.
- بترفع الدوال (الذكاء، الربط، الاستقبال).

**كل ما تضيف أو تغيّر مفتاح، شغّلها تاني.**

### 5) الاستضافة (Cloudflare Pages)
1. ادخل [dash.cloudflare.com](https://dash.cloudflare.com)، وبعدين **Workers & Pages → Create → Pages → Connect to Git**، واختار الـ Repository.
2. إعدادات البناء:
   - Framework: **None**
   - Build command: `node tools/build-web.mjs`
   - Output directory: `web`
3. Environment variables: `SUPABASE_URL` و`SUPABASE_ANON_KEY`.
4. **Deploy**. هتاخد رابط زي `synkroniza-bd.pages.dev`، وتقدر بعدين تربطه بدومين الشركة (مثلاً `bd.synkroniza.com`) من **Custom domains**.
5. ارجع لـ Supabase، **Authentication → URL Configuration**، وحط الرابط ده في **Site URL** و**Redirect URLs**.

### 6) الذكاء الاصطناعي (مجاني دلوقتي)
1. [aistudio.google.com](https://aistudio.google.com) ← **Get API key** ← حطه في `GEMINI_API_KEY` ← شغّل Setup Supabase.
2. لما يبقى فيه ميزانية: حط `ANTHROPIC_API_KEY` وشغّل Setup Supabase تاني.
   - المنصة بتفضّل Claude تلقائي لو مفتاحه موجود.
   - عشان تجبر مزوّد معيّن: `AI_PROVIDER` = `anthropic` أو `gemini` أو `openai`.
   - أي مزوّد متوافق مع OpenAI (مثلاً OpenRouter أو Groq) شغّال برضه: `OPENAI_API_KEY` + `OPENAI_BASE_URL` + `OPENAI_MODEL`.

> ⚠️ في الخطة المجانية، Google ممكن تستخدم البيانات لتحسين خدماتها. مابيعتبرش مشكلة لنصوص الكراسات (هي منشورة أصلاً). لكن لو هتحط بيانات حساسة، انقل لـ Claude أو لخطة Gemini المدفوعة.

### 7) Apollo
1. في Apollo: **Settings → Integrations → API → Create new key** ← `APOLLO_API_KEY` ← شغّل Setup Supabase.
2. من المنصة: **الربط والإعدادات ← Apollo ← جرّب**.
3. لو ظهر خطأ صلاحيات، فخطتك مابتسمحش بالـ API. ساعتها:
   - صدّر الليدز من Apollo كـ CSV.
   - استوردها من **توليد الليدز ← استيراد**. نفس النتيجة، بس يدوي.

### 8) إيميل الشركة (Microsoft 365)
محتاج مسؤول الـ Microsoft عندكم (5 دقايق):
1. [entra.microsoft.com](https://entra.microsoft.com) ← **App registrations → New registration**، باسم `Synkroniza BD`، Single tenant.
2. من صفحة التطبيق: `Directory (tenant) ID` ← `MS_TENANT_ID`، و`Application (client) ID` ← `MS_CLIENT_ID`.
3. **Certificates & secrets → New client secret** ← انسخ الـ Value ← `MS_CLIENT_SECRET`.
4. **API permissions → Add → Microsoft Graph → Application permissions** ← اختار `Mail.Send` و`Mail.ReadWrite` ← **Grant admin consent**.
5. `MS_SENDER` = الإيميل اللي المسودات والتقارير بتطلع منه، مثلاً `bd@synkroniza.com`. و`MS_DOMAIN` = `synkroniza.com`.
   - لو المستخدم داخل بإيميل على نفس الدومين، المسودة بتتحفظ في صندوقه هو.
6. شغّل Setup Supabase، وبعدين من المنصة: **الربط والإعدادات ← ابعتلي إيميل تجريبي**.

> 🔒 للأمان: اطلب من مسؤول Microsoft يعمل **Application Access Policy** يقصر التطبيق على صناديق فريق المبيعات بس، بدل كل صناديق الشركة.

### 9) أول دخول ونقل البيانات
1. افتح المنصة ← **حساب جديد**. **أول حساب بيبقى مسؤول النظام تلقائياً.**
2. في السيستم القديم (جوه Claude): **ملف الشركة ← النسخ الاحتياطي ← نزّل نسخة احتياطية**.
3. في المنصة: **ملف الشركة ← النسخ الاحتياطي ← استرجع من نسخة**. كده كل الحسابات والفرص والمناقصات والمهام اتنقلت.
4. ابعت رابط المنصة للفريق والمدير. كل واحد يعمل حساب، وانت تفعّله من **الفريق والصلاحيات**.

## الصلاحيات

| الصلاحية | يقدر يعمل إيه |
|---|---|
| مسؤول النظام | كل حاجة + إضافة الأعضاء وتغيير صلاحياتهم |
| مدير | يشوف ويعدّل كل البيانات والتقارير |
| تطوير أعمال | يضيف ويعدّل الحسابات والفرص والمهام والعروض |
| عرض فقط | يشوف من غير ما يعدّل (مناسب للإدارة العليا) |

كل البيانات **مشتركة ولحظية**: أي حد يضيف أو يعدّل، الباقيين بيشوفوه فوراً، وكل نشاط متسجّل باسم اللي عمله.

## الرصد اليومي — بيشتغل كل يوم 6:30 الصبح

| المهمة | بتعمل إيه | المصدر |
|---|---|---|
| رصد اعتماد | بتجيب المنافسات الجديدة المطابقة لكلماتك وتحطها في **توليد الليدز ← رصد المنافسات** | منصة اعتماد (صفحة الزوار) |
| الأخبار والإشارات | أخبار الحسابات المهمة، والشركات اللي عايزين نتسجّل في بواباتها، والمواضيع اللي حددتها. الذكاء بيقيّم كل خبر ويقترح إجراء | Google News (مجاني) |
| صندوق Leads | أي إيميل يوصل فولدر `Leads` بيتقري ويتحوّل لمنافسة أو خبر أو شركة | Microsoft 365 |
| إيميلات الصبح | كل عضو بيوصله «خطتك النهارده»، والمدير بيوصله تقرير الفريق عن امبارح (يوم الأحد بيغطي الخميس للسبت). ومفيش إيميلات يومي الجمعة والسبت | Microsoft 365 |

تعدّل الكلمات والشركات المتابعة من **ملف الشركة ← إعدادات الرصد**، وتشوف آخر تشغيل لكل مهمة من **الربط والإعدادات**.

### منصات المناقصات والتنبيهات (Tender Alerts، فرص، بوابات الموردين)
أغلبهم مالهمش ربط مفتوح، وبوابات الموردين (أرامكو، سابك، نيوم…) محتاجة تسجيل دخول. الحل العملي والمجاني:
1. سجّل في خدمة التنبيهات بالإيميل في كل منصة، بإيميل الشركة.
2. في Outlook اعمل فولدر اسمه **Leads**، واعمل **Rule**: أي إيميل من (Tender Alerts / فرص / اعتماد / بوابات الموردين) يتنقل للفولدر ده.
3. المنصة بتقرا الفولدر كل صبح وتحوّل كل تنبيه لمنافسة أو خبر.

> ملحوظة صريحة: لو منصة اعتماد منعت الطلب الأوتوماتيك (ده بيحصل أحياناً مع سيرفرات خارج السعودية)، هتلاقي ده مكتوب في **الربط والإعدادات**. ساعتها فعّل تنبيهات اعتماد على الإيميل، وهتوصل عن طريق صندوق Leads.

فيه طريقتين، والاتنين مجانيين. التفاصيل والـ Prompt الجاهز في [docs/manus.md](docs/manus.md).

2. **مباشر:** Manus بيبعت النتايج للمنصة بنفسه على رابط الاستقبال، وتظهر عندك من غير ما تعمل حاجة.

## تشغيل وصيانة
- **تحديث الكود:** أي تعديل يتعمل في الـ Repository، Cloudflare بيعيد النشر تلقائي. لو التعديل في `supabase/` شغّل Setup Supabase.
- **مزامنة الواجهة مع نسخة Claude:** `web/app.html` هو نفس ملف السيستم. لو اتحدّث، استبدله وشغّل `node tools/build-web.mjs`.
- **نسخ احتياطي:** Supabase المجاني مافيهوش نسخ احتياطي يومي تلقائي. نزّل نسخة من **ملف الشركة ← النسخ الاحتياطي** أسبوعياً.
- **خمول Supabase:** المشروع المجاني بيتوقف لو مااستخدمش أسبوع. المهمة اليومية بتمنع ده.
- **الحدود المجانية:**
  - Supabase: 500MB بيانات (تكفي آلاف الحسابات والكراسات) و50 ألف مستخدم شهرياً.
  - GitHub Actions: 2000 دقيقة شهرياً للـ Repo الخاص، والمهمة اليومية بتاخد 3–5 دقايق.
